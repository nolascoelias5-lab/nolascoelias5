# 🇧🇷 Português do Brasil — A0 a C1

Aplicación educativa en Streamlit para estudiar portugués brasileño desde A0 hasta C1.

## Archivos

- `app.py`: aplicación principal y contenido del curso.
- `requirements.txt`: dependencias de Python.
- `runtime.txt`: versión recomendada de Python.
- `.gitignore`: archivos que Git no debe subir.

## Ejecutar en tu computadora

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Publicar en Streamlit Community Cloud

1. Sube todos estos archivos a la raíz de un repositorio de GitHub.
2. En Streamlit Community Cloud crea una nueva aplicación.
3. Selecciona tu repositorio y rama.
4. En **Main file path** escribe:

```text
app.py
```

5. Pulsa **Deploy**.

No se requieren claves API ni archivos secretos para esta versión.
